# 分布式计算 · 中期研究交付

本科生创新训练培育项目（分布式计算方向）中期阶段的代码、图表、报告与数据快照。
主模型为分布式 FiLM-L（多节点校准 logit 平均），配套隐私副模型（MID）、通信缩减与年度更新机制。

## 大文件说明（重要）

GitHub 对仓库内单个文件有 100 MB 的硬性限制，因此以下三份 CSMAR 原始财务大表**没有**进入 Git 仓库，
本地工作目录中仍然保留原样：

| 文件 | 大小 | 原位置（相对 `最终展示交付/最终展示交付/数据/原始与对齐/原始X1_X2_X3_Y/X2 财务信息/`） |
|---|---|---|
| `FI_T4.xlsx`（经营能力） | 257.5 MB | `经营能力/` |
| `FI_T5.xlsx`（盈利能力） | 241.7 MB | `盈利能力/` |
| `FI_T1.xlsx`（偿债能力） | 129.0 MB | `偿债能力/` |

完整目录（含上述大表，约 972 MB）以 **Releases 附件**形式提供：
[gbsjs_full_972MB.zip](https://github.com/Esther080310/gbsjs/releases/download/midterm-full-archive/gbsjs_full_972MB.zip)。
该附件即本地的 `桌面分布式计算.zip`（GitHub 附件名不支持中文，下载后可自行改回）。
Release 页面：https://github.com/Esther080310/gbsjs/releases/tag/midterm-full-archive

解压后把三份大表放回上表所示目录即可，其余文件与本仓库内容一致。

其余数据（约 408 MB，1641 个文件，最大单文件为 30 MB 的 `x2.csv.gz`）已随仓库正常提交，克隆后可直接使用。

仓库为单次全量提交的干净历史（无中间版本），本地目录已初始化为 Git 仓库，后续更新可直接在此 `git add / commit / push`。

## 重画图表

不训练模型即可复现全部结果图，绘图数据已随仓库提供：

```bash
cd 最终展示交付/最终展示交付
pip install -r 代码/requirements-绘图.txt
python 代码/绘图/绘制三个原理图.py
python 代码/绘图/重画主模型原理.py
python 代码/绘图/重画结果图.py --only all
```
