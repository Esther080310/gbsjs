# 组员与AI操作指南

先把本文件和`图表与结果索引.csv`交给AI，再说明要改哪张图。不要让AI重新搜索项目里名字相似的旧实验。

## 改一张结果图

例如需要隐私与召回的取舍图：

1. 看`图表/结果图/10_隐私效用取舍.png`。
2. 打开`代码/绘图/重画结果图.py`，找到`privacy()`。
3. 数据来自`数据/绘图数据/隐私/task_comparison.csv`与`aggregate_comparison.csv`，不需要权重或torch。
4. 只改颜色、图例、字号或布局，执行：

```bash
python 代码/绘图/重画结果图.py --only privacy
```

输出会更新本目录下对应PNG和SVG，训练结果源表保持原样。图中小点是五次独立训练，菱形是均值；横轴是未恢复比例，不是“安全概率”。

## 改一张原理图

三个新增原理图统一位于`代码/绘图/绘制三个原理图.py`。`communication()`、`privacy()`、`update()`分别绘制通信、MID、年度更新。文字放在`box()`参数中，坐标也在同处；箭头用`arrow()`连接。修改后执行该脚本，PNG和SVG一起更新。

主模型和研究路径使用`重画主模型原理.py`包装原有布局代码。当前包装入口已经将旧图的548字节全浮点近似更新为545字节单模型账本，并注明六模型为3205字节。不要直接执行未包装的原始布局脚本当成最终版本。

## 改归因详细图

```bash
python 代码/绘图/重画结果图.py --only attribution-detail
```

这个入口会从冻结表重画行业×类型热图、审计分支开关后排序分布、字段依赖与恢复率、固定企业案例。支持量门槛已在数据中标记，低于20条的热图格子留空。修改图表时保留这一标记，不把小样本补成零。

## 想换核查预算

主模型各年完整排名在`数据/绘图数据/主模型/FiLM-L_2020_排名.csv`等文件。排序已冻结，每个企业一行。样本数N下，预算b使用k=ceil(b×N)，命中数为前k行记录正例标签之和。Precision=命中/k，Recall=命中/全表记录正例总数。无需插值或重新训练。现有1%、5%、10%图也按此逐行计算。

改图中显示的预算可以直接重画；若要改变正式模型选择指标或主要报告口径，应另行记录，不能以美化图表为由悄悄替换。

## 更新Word里的图

Word使用嵌入图片，不会随PNG自动变化。可以在Word中“更改图片”，也可以执行`代码/补全报告.py`从保留的上一版生成新报告。脚本会重新插入三张原理图并修正图号；直接在当前Word新增的手工文字不会被这个生成过程保留，因此手工改稿前先另存。

> 请先读本目录README、组员与AI操作指南、图表与结果索引。我要修改【图名】，只改变【字号/颜色/布局/预算展示】。请使用索引中指定的冻结数据和绘图入口，不训练模型、不改原始结果、不混用主模型六模型集成和MID五次独立训练。请保留微软雅黑和可编辑SVG，输出后查看PNG检查重叠。若重算了指标，请说明公式、样本范围和标签截止日。

## 图表里必须讲清的四件事

- 类型87.26%指“名单已经命中的正例”的条件Top2，不是全部企业的分类准确率；长尾宏覆盖约6.78%。
- 899 B相对同一六模型FP32接口3205 B，减少71.95%；不是相对集中式模型的全生命周期流量。
- 54.7%是指定容差下财务值恢复成功率，攻击视图为FP32；不能与FP16传输实验合并成形式化安全结论。
- 年度更新降低维护成本，但第二期召回低于每期全量重训；政策后的“两次全量”是工程配置。
