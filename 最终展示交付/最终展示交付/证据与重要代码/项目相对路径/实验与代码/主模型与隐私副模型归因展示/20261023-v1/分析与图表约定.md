# 主模型与隐私副模型归因展示约定

2026-10-23。固定FiLM-L主模型、五个共享S0与五个MID(0.1)。不训练或改选模型。

## 对象与预期

主模型是六个独立模型校准logit平均的实际预测器；S0和MID每次为一个共享编码器供六个融合头使用，五个种子分别评价。主模型与MID的直接差异包含架构变化，隐私效应主要看同种子S0/MID配对。

先验预期：财务节点仍占主要预测依赖；MID可能降低部分细节敏感性，同时保留主要指标排序。若节点贡献或指标顺序改变，将原样展示，不为符合叙事改案例或排序。

## 数据与样本

1. 继续加载开发任务2020的训练折0、验证折1（发生年2018），与隐私评价对齐。当前是单年度解释，不新增独立年度结论。
2. 制造业C和信息技术业I各固定随机抽64行，共128个用于节点总体描述；等量行业抽样不代表全市场行业比例。
3. 类型分组沿用此前固定148个已记录违规案例，解释P2503/P2504/P2505；不同类型可以重叠，只对模型依据作描述，不推断该指标造成违规。
4. 各行业从主模型前10%名单内已记录正例、名单外已记录正例中各选一个风险位置居中的案例，共4例。选择只依据主模型与既有记录，不依据MID表现挑案例。案例不加入随机样本统计。
5. 每行四个同行训练背景，排除同企业；同一行所有模型使用相同背景。MID使用原企业固定随机数，背景替换和关闭调制时保持随机数不变，避免把随机扰动误归给指标。

## 分析

- 三节点与审计调制：枚举16个组合，作4因素的精确Shapley分解。三个输入因素分别为X1、X2、X3治理事件；审计因素是启用/关闭FiLM调制分支。原审计输入保持，关闭分支通过令gamma、beta增量为零实现。完整节点替换时包含其缺失标记、完整率；X3包括治理状态、前16列，原审计7列保持不变。
- 分解基线为同行背景的三节点输入、关闭调制，完整端点为原输入、启用调制。检查加和恒等式。这是指定背景及分支干预下的模型输出分解，不把审计分支贡献等同于额外数据的独立预测增益。
- 主模型按原校准定义输出logit；S0/MID沿用副模型原始logit。跨模型图只比较模型内归一化的绝对贡献份额，不把不同校准尺度的绝对概率变化直接并列。
- 字段分析：固定13个财务隐私候选、两项企业年限、8个治理数值字段。只替换观测数值，缺失标记和完整率不动；输出总体风险与条件类型logit的敏感性，并归一化用于比较。字段替换可能打破关联关系，称替换敏感性，不称可加和SHAP或经济因果。
- 审计分析：在全部验证行比较启用/关闭FiLM。使用原始预测分数分布的ECDF位置，将输出变化表示为风险分位点差，便于不同分数尺度的模型展示。这个分位不是经过验证的风险概率。另比较财务字段替换敏感性在启用/关闭调制时怎样变化。
- 审计意见的原输入字段名、有效匹配数与分组人数先落盘。不解释gamma为原始财务指标的权重，它作用于88维潜在表示。
- 将MID的指标相对依赖与此前逐字段恢复成功率联系展示；低恢复能力不自动意味着该指标对任务贡献更小，图只作并列诊断。

4. 指标依赖与保护：13项财务指标的相对依赖与数值恢复成功率下降并列，源数值沿用已完成隐私攻击，不新训攻击器。
