# 共享编码器与信息约束隐私防护

先读[训练前约定](训练前约定.md)。本轮2020年开发小试验，主模型及旧结果保持原路径。

固定比较：S0共享编码器六头、D001/D01/D1三档距离相关、M0001/M001/M01三档变分瓶颈。每个企业只发一份本地表示，六个融合头共用。候选选择在fold1，只有预定入选臂才校准/测试。

```bash
实验与代码/.venv-literature/bin/python 实验与代码/FiLM-L隐私防护/20261021-v2/shared_privacy_experiment.py --phase all
```

已完成的训练臂从run.json识别，不覆盖；selection.json一旦写定不重选，final/summary.json完成后不重测。`execution.log`为首次执行，`execution-resumed.log`为校正旧模型校准参照后的续跑。[执行记录](执行记录.md)记录候选选择前的更正。

说明：545 B为137个数值槽（136个FP32和1个uint8）的表示载荷，不包含行业公共信息、包头、加密或梯度；尚未做本轮量化保真测试。随机瓶颈属于经验隐私防御，不构成差分隐私。

## 当前结果

七臂训练与验证筛选、S0一次最终审计均已完成。D/M没有同时通过预定效用与重构改善门，因此未进入最终测试。S0最终Recall@10%为31.89%（原六模型32.78%），AP为0.4781（原0.4927），完整重构增益由0.8357降至0.6914，属性AUC仍0.9988。当前不替换主模型、不扩展年度。

[结果解读](结果解读.md)包含验证选择、最终攻击、经济数值与缺失模式的拆分；数值独立核对在`results/independent_verification.json`；六头梯度与随机消息排序不变性在`results/structural_verification.json`。
