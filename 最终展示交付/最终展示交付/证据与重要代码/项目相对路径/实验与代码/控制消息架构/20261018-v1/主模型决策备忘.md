# 主模型决策备忘：选 FiLM-L（B），C 未通过归因检验

2026-10-18。C（`CMA-G`）已跑完，B（`FiLM-L`）已按"保留治理通道 + 线性调制头"重做并补齐三年。本文只陈述新证据与结论，配套的六条审计更正见 §4。

---

## 1. C 的结果：没有恢复精度

`CMA-G` = 节点 3 发 **8 float 治理摘要 + 8 float 审计控制码**（共 16 float，总预算 **123**）。

| 年度 | CMA-G − UA7 | 说明 |
|---|---:|---|
| 2020 | +0.085pp | 持平 |
| 2021 | −0.178pp | 持平 |
| **2022** | **−1.139pp** | 明显变差 |
| **三年等权** | **−0.433pp** [−0.905,+0.023] | 未恢复 |

**结论**：8 float 的治理摘要**替代不了** 21 float 的完整治理表示。CMA-L 那 0.32pp 的损失不能简单归因于"节点 3 预算太小"，而是"治理内容被整体删掉"。

## 3. 决策：选 B（FiLM-L）为主模型

四条理由：

1. **它是唯一真正"同信息、换接线"的臂**。我用输入扰动验证：改治理 16 列 → 预测变化 0.68；改 state → 1.04；改审计类别 → 1.77。**三个通道都在用**。（CMA-L 的对应值是 **0.0 / 0.0 / 1.86**——它把治理通道整个删掉了。）
2. **召回三年 −0.22pp、区间跨零**，是三臂中最好的；且逐年没有 2022 那种崩坏。
3. **AP 三年全正、2021 显著**——三臂中唯一有次级指标正向证据的。
4. **对全局网络两年 +0.27pp**（2020 +0.64、2021 基本持平），AP 两年都为正。

**必须同时写明的代价**：
- **消息预算仍是 128，没有任何通信收益**——这一点不能像 CMA-L 那样讲"−10.2%"；
- 参数 +3.1%；
- 召回是"**未检出差异**"，不是"证明等价"；不能说"损失不超过 0.5pp"（区间下界 −0.687）。

## 4. 定稿表述（替换此前所有关于主模型的说法）

> **主模型：审计条件化调制网络（FiLM-L）**
> 三节点纵向联邦，市场 16 float、财务 88 float、治理/审计 21 float，总消息 128 float。审计类别先编码为 8 维控制码，再以低秩乘性调制作用于财务表示（$\gamma,\beta$ 末层零初始化，训练起点与不接审计的模型一致）。
> 在 2020—2022 三个年度：前 10% 名单召回相对加性拼接结构 **−0.22pp［−0.69,+0.25］（未检出差异）**，整体排序 **AP +0.17／+1.04／+0.67（2021 显著）**；相对集中式代价敏感网络，两年召回 **+0.27pp**、AP 两年均为正。
> 参数 +3.1%，消息预算不变。

**创新点一句话**：把条件信息（审计意见）从"额外一路内容消息里的加性特征"改为"对财务表示的条件调制"，在不改变通信预算与信息集合的前提下，整体排序一致改善、名单召回不降。

## 5. 随之必须修正的六条（对应外部审计）

1. **CMA-L 的叙事作废**：它不是"同信息、更小接口"，而是"**以审计编码替代治理内容通道**"；"保留 87% 审计增量"撤回（两个模型差异里混着删信息）。
2. **"两种接线等价"改为**"接入方式在已测年度取得接近表现"，撤回"审计只能通过条件调制起作用"的机制断言。
3. **点估计全部改精确值**：CMA-L 逐年 **−0.318／−0.335／−0.318**；CMA-L − 全局 **+0.009pp**；`evaluate_final.py` 逐年字段的 bootstrap 均值改用精确值，并加断言。
4. **判据表述**：不是"六条事前判据全过"，而是"**五项事前判据 + 一项后加的参数量检查**，评价年度由两年扩为三年"。
5. **口径边界**：本轮属审计信息应用线（2023 年末固定标签快照），不得写成"解决了延迟/不完整监督"，也不与 $Y_{60}$ 实验合并成一张成绩表。
6. **成本与解释性**：128→115 是 UA7 vs CMA-L 的对比（不是全局 vs CMA-L）；FiLM-L 无通信收益；反事实差值标注为"**未校准分数变化**"；标准意见不变只是局部性检查，不证明无泄漏。
7. **E1 变化编码**：`argmax` 含匹配位导致第 0 列与"任意变化"列重复、第 1—6 列恒零 → 撤回"各类审计转变价值"的结论，仅保留"变化指示实验"的描述。
