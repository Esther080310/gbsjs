# 控制消息架构（CMA）：以微小精度换结构创新 —— 预注册

2026-10-18。**先落盘，后运行。**

## 1. 动机与已测事实

E2 轮已证明：审计信息的效果来自**对财务表示的条件调制**（同 7 维，改为 FiLM 后仍拿回全部增量：+2.418pp vs +2.322pp，差 +0.096pp 跨零）。但 FiLM 方案仍保留 21 float 的第三方内容消息，且参数量更高。

本协议把它升级为**架构主张**：**条件信息不应作为内容消息传输，而应作为控制信号调制其他节点的表示。**

## 2. 结构（唯一变动）

| | 现状 `UA7` | **`CMA`** |
|---|---|---|
| 节点 1 内容 | 16 | 16 |
| 节点 2 内容（财务） | 88 | 88（被控制码调制） |
| 节点 3 内容（治理/审计） | **21** | **8（控制码）** |
| 消息总 float（含 3 个 q） | **128** | **115（−10.2%）** |
| 审计进入方式 | 拼进 X3 + 加性分支 | 控制码 → FiLM 调制财务表示 |
| 参数量 | 37,375 | 41,280（+10.4%，需如实报告） |

控制码 $c=\tanh(Wa)\in\mathbb R^8$；调制 $h_2\leftarrow h_2+r\odot(\gamma(c)\odot h_2+\beta(c))$，$\gamma,\beta$ 末层零初始化（训练起点与 U0 逐值相同）。$r$ 为审计匹配标志。

## 3. 判定（事前固定，**非劣性 + 结构性收益**）

1. **非劣性**：`CMA − UA7` 两年合并点差 ≥ **−0.5pp**（允许小幅让渡，用户已明确接受）；
2. **区间**：两年合并配对区间**下界 > −1.2pp**（排除"大幅变差"）；
3. **逐年**：2020、2021 各自点差 ≥ −1.0pp；
4. **AP**：`ΔAP ≥ −1.0pp`；
5. **预算**：消息总 float **≤ 128**（本结构为 115）；
6. **机制可读**：控制码对审计类别**有区分度**——不同类别的控制码两两欧氏距离中位数 > 同类内（同一类别、不同企业）距离中位数；且各类别的 $\lVert\gamma(c)\rVert_2$ 存在可解释差异（非全同）。

6 条全部满足 → **采用为结构性贡献**（以"精度持平 + 通信降 10% + 机制可读"作为卖点）；任一不满足 → 不采用，并写明差在哪。

**不做的**：不在 2020/2021 上调控制码维度、调制秩、种子；不因结果改判据。

## 4. 附带的解释性产出（不需训练）

对评价年的非标意见企业，做**反事实替换**：把审计向量换为"标准无保留"，重算风险分，得到 $\Delta$ 风险 = 审计信息对该公司分数的贡献。报告 $\Delta$ 的分布与排名靠前的公司——这是"控制码可解释"的直接证据。

## 5. 预算与统计

12 次拟合（6 种子 × 2 年度，单次约 4 秒）。两年等权，公司聚类配对 bootstrap 2,000 次（seed 20261018），共用企业抽样（C5）；点估计精确、bootstrap 均值另报（C2）；两侧均为 6 种子单模型均值（C3）；判据完整断言（C1）。
