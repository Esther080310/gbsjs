# 控制消息架构（CMA）：以 −0.37pp 换取结构创新，通信降 10.2%，并通过 6/6 事前判据

2026-10-18。按[训练前约定](训练前约定.md)执行：12 次拟合（6 种子 × 2 年度，单次约 3.5 秒）。**判定：6 条事前判据全部通过 → 采用为结构性贡献。**

---

## 1. 结构变化（唯一变动）

| | 现状 `UA7` | **`CMA`** |
|---|---|---|
| 节点 1 内容消息 | 16 float | 16 |
| 节点 2（财务）内容消息 | 88 | 88（被控制码调制） |
| 节点 3（治理/审计）内容消息 | **21** | **8（控制码）** |
| 消息总 float（含 3 个 q） | **128** | **115（−10.2%）** |
| 审计进入方式 | 拼进 X3 + 加性分支 | 控制码 $c=\tanh(Wa)$ → FiLM 调制财务表示 |
| 参数量 | 37,375 | 41,280（**+10.4%**，如实报告） |

调制：$h_2 \leftarrow h_2 + r\odot(\gamma(c)\odot h_2+\beta(c))$，$\gamma,\beta$ 末层零初始化（训练起点与 U0 逐值相同），$r$ 为审计匹配标志。

## 2. 六条判据

| 判据 | 结果 |
|---|---|
| 1. 非劣性：点差 ≥ −0.5pp | **−0.367pp** ✓ |
| 2. 区间下界 > −1.2pp | **[−0.891, +0.126]** ✓ |
| 3. 逐年 ≥ −1.0pp | 2020 **−0.523**／2021 **−0.217** ✓ |
| 4. ΔAP ≥ −1.0pp | **+0.398pp**（更好） ✓ |
| 5. 消息总 float ≤ 128 | **115** ✓ |
| 6. 控制码有类别区分度 | ✓（见 §3，但需按下述方式解读） |

**采用判定：`adopt = true`。**

**成本与收益的准确表述**：以 **−0.37pp 召回**（区间跨零、在噪声范围内）换 **消息量 −10.2%**，AP 反而 +0.40pp；参数 *增加* 10.4%——所以"更省"只在**通信**口径成立，不在参数口径。不得写成"更轻量"。

## 3. 可解释性（三条证据，按强弱排序）

**(1) 反事实归因（最强）。** 把某公司的审计向量替换为"标准无保留"后重算分数（6 种子平均）：

| | 2020 | 2021 |
|---|---:|---:|
| 非标意见公司：平均风险下降 | **13.1pp** | **14.2pp** |
| 标准意见公司：平均风险变化 | 0.000002 | 0.000004 |
| 最大单家下降 | 37.4pp | 35.1pp |

即：**对非标公司，抹掉审计信息会让其风险分数平均掉 13 个百分点，最高掉 37 个百分点**；对标准意见公司则完全不变（说明反事实替换是局部的、没有污染其他信息）。这给出了**逐家可核查的审计贡献**。

**(2) 调制强度随审计严重程度上升。** 各类别的 $\lVert\gamma(c)\rVert_2$ 均值：标准无保留 **6.74** → 带说明段 7.95 → 保留意见 7.76 → 无法表示/否定 **8.33**。非标类别对财务表示的调制明显强于标准类别。

**(3) 控制码是"类别嵌入"。** 同类企业的控制码完全相同（类内距离 0），类间中位距离 0.85。**必须注意**：判据 6 的"分离比"因此退化为除零产生的大数，**不应作为证据引用**；真正的证据是 (1)(2)。

## 4. 与已有结论的关系

- 与 E2 的机制结论一致：审计信息作用于**财务表示的条件调制**，而不是独立信号；
- 与审计线的主结论不冲突：审计增量（+2.234／+2.676pp）是在 `UA7` 结构下测的；CMA 复现了其中绝大部分（相对 U0 的效用大致保留，仅比 UA7 低 0.37pp）；
- 与"消息预算 128 float"的既有约束兼容，且**把预算降到 115**，为后续接入更多信息留出 13 float。

## 5. 局限（必须写进论文）

1. **只换结构，不换信息**：CMA 与 UA7 使用完全相同的输入，因此它证明的是"接线方式"的等价与可解释，**不是**新信息带来的提升；
2. **精度略降**：−0.37pp（区间 [−0.891,+0.126]），在噪声范围内但方向为负；
3. **参数更多**（+10.4%）：不能用"更小模型"叙事；
4. **无新年度确认**：只有 2019/2020/2021 这批开发回放中的 2020 与 2021；
5. **控制码维度（8）与调制秩未做扫描**——按协议不调；若论文需要，应作为独立预注册实验。

## 6. 可用的创新点表述（可直接写进 PPT）

> **提出"控制消息"式的纵向联邦结构**：把条件信息（审计意见）从"独立内容消息"改为"编译成 8 维控制码、调制他方表示"。在保持精度持平（−0.37pp，区间跨零）的同时把第三方消息从 21 float 压到 8 float、总预算从 128 降到 115（−10.2%），并给出**逐家企业可核查的审计贡献**（非标公司风险平均下降 13pp，最高 37pp）。
