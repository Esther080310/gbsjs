`文件来源与校验.csv`记录整理复制的每份原文件、交付路径、大小和SHA256。新生成文件另见`检查记录/最终文件清单.csv`。

报告旁有同名Markdown正文，便于AI读取和逐段编辑；图表的源数据和脚本仍以图表索引为准。正式Word为15页、10张图、7个表。重画层共20张图，均提供PNG和文字可编辑SVG。

## 一次重画

在本目录运行。当前Mac可使用项目已有环境：

```bash
../实验与代码/.venv-literature/bin/python 代码/绘图/绘制三个原理图.py
../实验与代码/.venv-literature/bin/python 代码/绘图/重画主模型原理.py
../实验与代码/.venv-literature/bin/python 代码/绘图/重画结果图.py --only all
```

换电脑时安装`代码/requirements-绘图.txt`，再把上面的Python路径换为自己的Python。常用绘图入口使用相对路径，整份目录可复制后重画。字体在`字体`中供本组本地复现；字体外发按其授权处理。

本交付提供独立重画能力。原训练代码快照仍有历史绝对路径和动态依赖，跨机器重新训练前按`重要代码与数据索引.md`配置，不能把“图能重画”当成“完整训练环境已经封装”。旧PPT尚未同步本轮原理图，当前以本目录Word和图表为准。

## 冻结口径

正式FiLM-L：六个独立模型的校准logit平均；2020—2022年，标签固定至2023-12-31。MID：同构共享编码器，五次独立稳定性复检，五种子不作为上线集成。年度更新：两期历史回放、三种子、按历史截止日构造训练标签。三组数据不能合成一个预测器或一个统一平均数。
